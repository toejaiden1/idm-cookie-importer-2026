## 🍪 How Cookie Importing Works

Websites use small files called cookies to remember that you're logged in. When you visit a site and sign in, your browser stores a cookie. IDM normally doesn't have access to those cookies, so it can't prove to the website that you're an authorized user.

This tool bridges that gap. It reads the cookie data from your chosen browser's storage, converts it into a format IDM understands (the standard Netscape cookie format), and pushes it into IDM's system. After that, IDM can initiate downloads from protected areas of websites with your full access rights.

The best part? You don't need to understand any of the technical details. The application does everything automatically in the background.

## ❓ Frequently Asked Questions

### Do I need to re-import cookies every time?

Cookies have expiration dates. Depending on the website, they can last from a few hours to several months. When a download fails with an authentication error, simply run the importer again to refresh your session.

### Will this work with any website?

It works with any website that uses standard cookie-based authentication. Some sites use additional security measures like CAPTCHAs or device fingerprinting, which may still block automated downloads.

## 🔧 Troubleshooting

### Import Succeeds But Downloads Still Fail

This usually means the cookies have expired. Log back into the website in your browser, then re-run the importer.

### Browser Not Detected

Make sure the browser is installed in its default location. If you moved it, the tool may not find it. Reinstall the browser to its standard directory.

### IDM Not Found

The tool needs to locate IDM's installation folder. If IDM is installed in a non-standard location, the importer might not find it. Reinstall IDM to the default path.

### Antivirus Warnings

Some antivirus programs may flag the tool because it accesses browser data. This is a false positive. Add the application to your antivirus whitelist if necessary.
